# Utility Helpers (`client/src/utils`)

This directory houses helper functions, formatting utilities, and date/time handlers.

## Planned Utilities
- `formatters.js`: ABHA 14-digit formatters, phone number sanitizers, and Indian currency/numeric notations.
- `validators.js`: Clinical vitals boundary validations (SpO2, BP systolic/diastolic, Pulse, Temp).
- `date-helpers.js`: Longitudinal timeline timestamping and relative time calculations.
