# Doctor / Medical Officer (MO) Module (`client/src/pages/doctor`)

This directory represents the clinical workstation views for Medical Officers at Primary Health Centres (PHCs) and Sub-District Hospitals (SDHs).

## Key Screens & Features
- **Clinical Station Queue**: Triage priority inbox sorted by risk stratification (EMERGENCY / HIGH RISK / MODERATE).
- **Consultation & Tele-Prescription**: Electronic prescription intake, doctor clinical notes, oxygen bay assignment, and automated post-discharge follow-up delegation back to frontline ASHAs.
- **Referral Inbox**: Real-time ambulance transit notifications and emergency incoming transfers.
