# Health Administration Module (`client/src/pages/admin`)

This directory represents the public health administration and district surveillance views for Chief Medical Officers (CMO) and District Health Officers (DHO).

## Key Screens & Features
- **District Analytics Overview**: High-level surveillance metrics (total registered population, active high-risk escalations, offline sync rates, transit times).
- **Facility Readiness & Capacity**: District-wide bed capacity, oxygen concentrator status, and referral traffic distribution across PHCs, CHCs, and District Hospitals.
