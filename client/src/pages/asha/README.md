# ASHA Frontline Worker Module (`client/src/pages/asha`)

This directory represents the frontline healthcare worker workflows and views for Accredited Social Health Activists (ASHA).

## Key Screens & Features
- **Dashboard**: Operational Hub showing daily village visit metrics, high-risk flags, active referrals, and quick registration.
- **Registration Wizard**: Multi-step offline-first intake form capturing patient demographics, ABHA number, clinical symptoms, and live vitals.
- **Facility Finder**: Nearest PHC/SDH/District Hospital locator sorted by distance and critical capabilities (Oxygen concentrators, ICU, ambulance).
- **Referral Tracking**: Inter-facility digital transfer token generator and status monitor.
